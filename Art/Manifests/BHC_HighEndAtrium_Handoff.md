# BHC high-end atrium handoff

The first premium environment pass is an editable Blender scene and a GLB export. It establishes the visual language for the game: dark marble, aged brass, burgundy velvet, emerald felt, smoked graphite, and controlled red/purple neon. The scene includes an atrium shell, a central oversized Big Head centerpiece, table-game props, slot cabinets, a daily wheel stage, lounges, balcony railings, original signage, and a hero camera render.

Files:

- `Art/Blender/BHC_HighEndAtrium.blend` — editable source.
- `Art/Blender/build_high_end_atrium.py` — repeatable build script.
- `Art/Exports/BHC_HighEndAtrium.glb` — exchange export.
- `Art/Previews/BHC_HighEndAtrium_Hero.png` — render proof.

The export is a visual art batch, not a completed Unreal level. Unreal import, collision proxies, LOD authoring, material instance setup, Nanite decisions, interaction sockets, and final performance profiling remain integration work.
